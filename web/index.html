ePager firmware installer

Flash an ePager board from your browser over USB. Nothing to install.

1. Pick your board

2. Connect it

  1. Plug the board into this computer with a USB cable that carries data (a charge-only cable shows no port).
  2. Click Install, pick the board's serial port in the browser's dialog (usually “USB JTAG/serial debug unit” or “ESP32-S3”), and wait until it says done. Keep the cable plugged in meanwhile.
This browser cannot flash over USB. Use Chrome, Edge or Opera on a desktop computer (Firefox and Safari do not support Web Serial). Web Serial needs a secure page (HTTPS). Open this page over https:// or from localhost.

This is an unsigned development build: it runs normally, but it will not accept over-the-air updates from the phone app later.

The LCD board has no BOOT key. Its only way back from a bad image is USB, so leave the cable connected until the install ends. Want the original firmware back later? Back it up first (see “Restore” below).

What gets written

  • The bootloader, the partition table, the boot-slot data and the application, at fixed offsets.
  • Settings, paired phones and saved Wi-Fi networks stay when the partition layout is unchanged, so updating a board that already runs ePager keeps them. Tick Erase device in the dialog for a clean start; the first install over a different firmware (for example the stock one) should use it.

Trouble

The port list is empty or the install fails to connect
  • Paper: unplug the cable, hold BOOT, plug it in, release BOOT, then try again. The chip is then in its ROM download mode.
  • LCD: there is no BOOT key. Unplug and replug the cable and try again; if the firmware was sleeping, press a volume key first.
  • Linux: your user needs access to /dev/ttyACM*: sudo usermod -aG dialout $USER, then log out and in.
  • Close other programs that hold the port (serial monitors, idf.py monitor).
Restore the original firmware (LCD board)

This page cannot restore the stock firmware. Before the first install, read the whole flash with esptool.py --chip esp32s3 -b 921600 read_flash 0 0x1000000 backup.bin and keep the file private (it holds the vendor's stored Wi-Fi passwords). Restore steps: docs/recovery.md.
